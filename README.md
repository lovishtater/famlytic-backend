# Famlytic Backend

This is an experimental project to explore and learn Neo4j database for managing complex family relationship data.

## About Famlytic

Famlytic is an intelligent family tree platform that helps you discover your family story through visualization. It provides interactive family tree visualization.

## Tech Stack

- Node.js with Express
- Neo4j (graph database for relationships)
- MongoDB (for user contacts)
- OpenAI (for AI-powered queries)
- Google APIs (for contacts integration)
